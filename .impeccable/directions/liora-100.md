# Liora 1.0 — direction contract

Mode: Operate. User-pinned redesign: Discord mental model, existing Liora identity, real workflows, safe upgrade from production 0.7.1. Code-led: no approved image comp and no invented imagery.

FIRST VIEWPORT: narrow rail distinguishes personal home, messages and workspaces. The adjacent sidebar names the active context and shows personal tools OR workspace categories/channels. Main content identifies the channel, project or calendar. Channel context displays actual members, threads, pins and files. Graphite, Manrope, restrained sage accents, single geometry across the ten preserved theme IDs.

Signature interaction: select a workspace from the rail, return to its stored view/channel, then open a scoped profile or entity action using right click, Shift+F10 or the visible ellipsis. Native menus remain available in editors, inputs and code. Escape restores focus.

Mobile: same rail and product hierarchy; navigation and channel context use dismissible drawers with focus handling. Bottom dock provides personal/friends/navigation entrypoints. Real forms and menus remain usable at 320px. No horizontal page overflow.

Required behavior: personal reminders/inbox/favorites work across memberships and with zero workspaces; private channels/DMs and effective permissions remain enforced server-side. TEXT/EMBED webhooks share validated previews and actual message publication/history. CalDAV setup shows per-device credentials, one-time password and revocation. Pages UI and Google runtime integration retire while historical tables and Pages API remain intact. No En direct label.

Quality bar: visible context, no decorative conversation introduction once messages exist, readable hierarchy, clear active/unread states, actual callbacks, keyboard/focus/escape and phone reachability. Preserve data and external integration boundaries. Screens contain named demonstration data and synthetic Kyros identity; they do not qualify a production/provider/device release.

Scope: AppShell/main/navigation, chat/channel settings/context/profiles, centralized entity menus in Kanban/calendar/notes/integrations/webhooks/files, personal surfaces, CalDAV and consolidated CSS/themes. Existing business modules retain their contracts. Stable 1.0.0 requires additional real-client/security/production qualification; this code is 1.0.0-beta.1.
